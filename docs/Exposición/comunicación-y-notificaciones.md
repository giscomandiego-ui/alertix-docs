Alertix permite mantener una comunicación directa entre Padres de familia y Enfermería.

Los padres pueden iniciar un chat para comunicarse con Enfermería, mientras que el personal puede recibir y gestionar estas conversaciones desde su panel.

Además, Alertix utiliza notificaciones para avisar sobre eventos importantes dentro de la plataforma y facilitar un seguimiento más rápido.

Padre → Chat → Enfermería → Notificación
