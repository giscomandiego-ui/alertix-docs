### Iniciar sesión

El usuario puede acceder mediante:

- **Correo y contraseña**
- **Google**

Después de iniciar sesión, Alertix identifica automáticamente el rol del usuario y lo dirige a su **Panel General** correspondiente.

### Seguridad

Si no existe una sesión válida, el usuario no puede acceder a las funciones internas de Alertix.

Cada usuario solamente puede acceder a la información y herramientas permitidas para su rol.
