### Activar mi cuenta

Las cuentas de Alertix son creadas por un administrador. Cuando se crea una cuenta nueva, el usuario recibe un **correo de activación** para establecer su contraseña y completar el acceso.

### Activar una cuenta nueva

1. Abre el correo de activación enviado a tu dirección registrada.
2. Selecciona el enlace de **Activar cuenta**.
3. Alertix abrirá la pantalla para establecer tu contraseña.
4. Introduce una contraseña nueva y confírmala.
5. Selecciona **Establecer contraseña y activar cuenta**.

Una vez completado el proceso, tu cuenta quedará activa y podrás iniciar sesión normalmente.

### ¿No recibiste el correo?

Revisa primero las carpetas de **Spam**, **Correo no deseado** o **Promociones**.

Si todavía no encuentras el mensaje, solicita al administrador que **reenvíe el correo de activación**.

### Importante

El enlace de activación es personal y debe utilizarse desde la cuenta de correo a la que fue enviado.

Si el enlace expiró o dejó de ser válido, solicita un nuevo enlace de activación.
